Open WebUI (OpenAI-compatible) для AI-ассистента DBeaver CE — установка без интернета, версия @VERSION@
=========================================================================================

Подходит для DBeaver CE 26.2.x и 25.2.4–25.2.5 на Windows. Интернет и Eclipse Marketplace не нужны:
всё, что требуется плагину (Gson, модули AI-ассистента), уже входит в DBeaver.

Состав пакета
  dbeaver-openwebui-ai-site-@VERSION@.zip  — архив для «Установить новое ПО» (основной способ)
  install.cmd                              — то же самое одной командой, без окон DBeaver
  plugins\*.jar                            — модули для ручной установки (запасной вариант)


Способ 1. Через меню DBeaver (рекомендуется)
--------------------------------------------
Пункт меню есть и без Marketplace.
1. Справка → Установить новое ПО… (Help → Install New Software…)
2. Добавить… → Архив… → выберите dbeaver-openwebui-ai-site-@VERSION@.zip → Добавить.
3. ВАЖНО: внизу окна снимите галочку «Связаться со всеми сайтами обновлений во время установки
   для поиска требуемого ПО» (Contact all update sites during install to find required software).
   Без интернета с этой галочкой установка зависает или падает с ошибкой сети.
4. Отметьте категорию «Open WebUI integration» целиком. Для фоновых запросов и сохранения AI-чатов
   (только DBeaver 26.2+) отметьте ещё «Open WebUI: add-ons → Open WebUI: background chats».
   Далее → Далее → примите лицензию → Готово.
5. На вопрос о неподписанном ПО ответьте «Установить всё равно» и перезапустите DBeaver.
Старые версии плагина (1.x, 2.x) заменяются автоматически.


Способ 2. Скриптом
------------------
1. Закройте DBeaver.
2. Распакуйте пакет в папку БЕЗ пробелов в пути, например C:\openwebui-offline
3. В командной строке (если DBeaver лежит в Program Files или в общей папке — от имени
   администратора) укажите папку, где лежит dbeaver.exe:

     C:\openwebui-offline\install.cmd "W:\app\dbeaver"

   С надстройкой «Фоновые чаты» (DBeaver 26.2+) — с ключом async:

     C:\openwebui-offline\install.cmd "W:\app\dbeaver" async

   В конце должно быть: [OK] Plugin installed.


Способ 3. Вручную (если p2 не работает)
---------------------------------------
1. Закройте DBeaver.
2. Скопируйте plugins\dbeaver.openwebui.ai_@FULLVERSION@.jar в <папка DBeaver>\plugins\
3. Откройте <папка DBeaver>\configuration\org.eclipse.equinox.simpleconfigurator\bundles.info
   - удалите строки, начинающиеся с io.dbtools.openwebui и dbeaver.openwebui (старые версии);
   - добавьте в конец строку:
     dbeaver.openwebui.ai,@FULLVERSION@,plugins/dbeaver.openwebui.ai_@FULLVERSION@.jar,4,false
4. Запустите DBeaver.
Папка dropins в DBeaver 25.x/26.x не работает, класть jar туда бесполезно.


Проверка
--------
Справка → Сведения об установке → «Подключаемые модули» → фильтр openwebui:
должна быть строка dbeaver.openwebui.ai @VERSION@.
В настройках AI в списке движков появится «Open WebUI (OpenAI-compatible)».


Ошибка «AI engine openwebui not found» / «N/A» в окне чата
----------------------------------------------------------
Настройки AI хранятся в профиле пользователя (%APPDATA%\DBeaverData\workspace6\.metadata\.config\
ai-configuration.json). При перемещаемом профиле Windows они переезжают на другой компьютер вместе
с выбранным движком openwebui, а сам плагин там не установлен. Отсюда ошибка в настройках и пустой
чат с надписью N/A. Установите плагин на этом компьютере любым способом выше.

Если после установки чат по-прежнему показывает N/A: Окна → Настройки → Пользовательский интерфейс →
группа «Web browser» → Web Engine = Microsoft Edge, перезапустить DBeaver. На Windows Server
2016/2019 для этого нужен Microsoft Edge WebView2 Runtime (автономный установщик x64 от Microsoft).
